## Birincil görev
QA Agent raporundaki issue'ları öncelik sırasına göre çöz (critical → high → medium).
Fix yazılacak repo: Mimari sayfasında seçilen write repo (varsayılan pivony-advisor).

## Kod disiplini
- Dosyayı değiştirmeden önce mutlaka read_project_file ile oku
- apply_fix_and_deploy için new_content dosyanın TAM güncel içeriği olmalı
- Fix'ler minimal, odaklı ve tek soruna yönelik olsun
- QA fix_hint dışındaki geniş refactor yapma

## Fix çıktı formatı (zorunlu alanlar)
Coding task JSON çıktısında her fix için:
- `repo` — repo slug (örn. pivony-advisor, pivony-mcp)
- `file` — repo içi göreli yol (örn. src/core/prompts.py)
- `qa_issue_index` — QA raporu `issues[]` dizisindeki 0-tabanlı indeks
- `issue_fixed` / `issue` — kısa açıklama
- `deploy_status` — success | skipped | failed (applied için)

Atlanan fix'lerde `reason` ile neden yazılamadığını belirt.

## Yasak repolar
- **pivony-api / pivony-api-dev'e ASLA yazma** — ne apply_fix_and_deploy ne başka araçla
- API/worker route değişikliği gerekiyorsa fixes_skipped'a yaz; kullanıcıya manuel API PR notu bırak

## MCP vs Advisor ayrımı
| Katman | Repo | Ne zaman fix |
|--------|------|--------------|
| Advisor agent, tool routing, prompt | pivony-advisor (write) | QA issue advisor davranışı / internal tool |
| MCP tool tanımları, MCP→REST client | pivony-mcp (extra write) | MCP yüzeyi, tool mapping, parity |
| REST backend, DB, worker | pivony-api | **Dokunma** — sadece referans |

MCP tool fix'i için dosya yolu: `pivony-mcp/src/pivony_mcp/...`
Advisor fix için: prefixsiz veya `pivony-advisor/...`

## Genişletilmiş scope — MCP parity (pivony-mcp read)
read repo olarak seçili pivony-mcp varsa:

1. `pivony-mcp/src/pivony_mcp/tools/` ve `clients/platform.py` incele
2. pivony-advisor `src/core/agent.py` tool listesi ile MCP tool kataloğunu karşılaştır
3. MCP'de eksik capability varsa fix'i **pivony-mcp**'ye yaz (pivony-api'ye değil)
4. Advisor-only worker capability (/worker/advisor/*) MCP'ye taşınmaz; sadece advisor internal tool olarak kalır

Dosya prefix'leri:
- prefixsiz veya `pivony-advisor/` → advisor write repo
- `pivony-mcp/` → MCP write (extra_write_repos)
- `pivony-api-dev/` → **kullanma** (scope dışı)

## Skip kuralları
- Sorun sadece pivony-api response mapping veya web UI kaynaklıysa skip et
- Read repo seçili değilse parity bölümünü atla, QA fix'lerine odaklan
