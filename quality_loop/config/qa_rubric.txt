Pivony Advisor yanıtlarını şu kriterlere göre değerlendir:

## Bağlam Yönetimi (0-10 puan)
- Dashboard seçildikten sonra hatırlıyor mu?
- Önceki turların bilgisini kullanıyor mu?
- Aynı soruyu tekrar soruyor mu?
- org_wide kullanımı seçili dashboard varken tetikleniyor mu?

## Tool Kullanımı (0-10 puan)
- Doğru tool'u kullandı mı? (get_trends, get_topic_trends, list_reviews, get_pivony_metrics)
- Tool parametreleri doğru muydu? (dashboard_id, org_wide, days, topic)
- Tool başarısız olduğunda ne yaptı?

## Yanıt Kalitesi (0-10 puan)
- Soruyu gerçekten yanıtladı mı?
- Veriyi doğru yorumladı mı?
- Önerdiği follow-up'lar mantıklı mı?

## Hata Yönetimi (0-10 puan)
- Hata mesajı kullanıcıyı yanıltıyor mu?
- Çözüm yolu sundu mu?
- Bağlamda çözüm varken "yapamam" dedi mi?

## Session sınırı (zorunlu)
- Önce `fetch_conversation` ile **hedef session_id** konuşmasını oku.
- `message_index` = fetch_conversation.messages[] içindeki 0-tabanlı indeks (her satırda message_index alanı var).
- YALNIZCA bu dizideki indeksleri kullan; `message_count` dışındaki indeksler geçersizdir.
- `fetch_advisor_logs` / history.log kayıtları **ek kanıt** içindir; başka session veya log satırından message_index türetme.
- fetch_recent_sessions kullanma (QA agent'ta yok).

## Log analizi (zorunlu)
Her değerlendirmede `fetch_advisor_logs` kullan:
- **logs/history.log** — gerçek API audit (messages, assistant_response, model)
- **logs/advisor.log** — sunucu ERROR/WARNING/traceback, rate limit, tool exception

Advisor yüzey yanıtı ("Yanıt oluşturulurken hata", dashboard_picker eksikliği vb.) yanıltıcı olabilir.
Issue `evidence` alanına hem conversation hem log satırı koy (ör. advisor.log traceback).

Log'da kök neden varsa ama kullanıcıya generic mesaj gittiyse → `misleading_error` (yüksek severity).

## Bilinen risk alanları (pivony-advisor)
- src/core/agent_state.py — hard scope resolution (analytics_scope vs dashboard_selection)
- src/core/tool_routing.py — pin_tool_args_for_state, list_dashboards gating
- src/core/analytics_scope.py — infer_established_analytics_scope org_wide fallback
- Web tarafı (pivony-web-platform): util/advisorAnalyticsScope.js — session scope retention
- API tarafı (pivony-api): dashboards.py cx_gpt chat page_context mapping
